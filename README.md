# MLCPTE
 Machine Learning-Chemical Pressure for Low Thermal Conductivity Thermoelectrics

Contents Overview:
"ML-CP training" and “trained ML-CP model” contain code from the original ML-CP project. “code” contains the code files used in this project. The manuscript for this project is Thesis.pdf. The remaining files are database data, reference data files, data generated by the code. 

Packages Needed:
This project runs in python 3.12.2 with Jupyter Notebook. The following packages are needed: time, warnings, pickle, math, scipy, itertools, numpy, pymatgen, os, pandas, matplotlib, seaborn, plotly, importlib, sklearn, urllib, and json

Getting Started:
To produce the classifier and regressor models (saved as rfc.pickle and rfr.pickle), download the files contact_data_by_cp.xlsx, element_data.xlsx, and machine_learning.py or machine_learning_code.ipynb from the "ML-CP training" directory. With these files in the same local directory, run the command 

python3.8 machine_learning.py
To generate the rfc.pickle and rfr.pickle models automatically, or run all of the lines in machine_learning_code.ipynb manually to get the same results.

These models should be placed in a folder along with the element_data.txt file. This folder will serve as the primary working directory, and any of the ML-CP code files will work here to generate ML-CP data. A file called "IMAGES" should be created within this file to house generated images.
